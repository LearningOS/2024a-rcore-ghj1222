# 实现的功能

实现了一个 get_inode_by_pos，因为内存inode没有存inode id，所以要转换一下，但是更阳间的写法是内存中inode存一下inode id

把磁盘中 inode 的 直接索引缩小了一个，然后存一个 refcnt 来表示它是多少个文件的硬链接，初始化是1

linkat 中先找到 old_name 的 inode，将其refcnt 加1,然后在new_name的位置新建一个dentry，将其inode id设置过去

unlinkat中先找到dentry对应的inode，将其refcnt减少1,然后删除这个dentry（可以将最后一个dentry移动到当前位置来删除）。如果refcnt减到0就释放inode的所有空间，包括它自己的inode map位置也释放

stat 只需要实现一个 file trait，来获取对应的信息
